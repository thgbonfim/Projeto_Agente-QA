# 🚜 Squad Digital Autônoma - 100% Local AI Driven

Este projeto demonstra uma pipeline de engenharia de software **Totalmente Local e Autônoma**, orquestrada por agentes de IA que utilizam modelos de linguagem de última geração para gerir o ciclo de vida do desenvolvimento (SDLC).

## 🤖 Agentes da Squad (Ollama Core)
1. **Agente P.O. (Product Owner)**: Traduz necessidades de negócio em Stories no Jira com critérios de aceite técnicos e IDs mapeados.
2. **Agente DEV**: Monitora o 'To Do', analisa o `index.html` existente e implementa novas funcionalidades via **Qwen 2.5 Coder**, preservando o Design System.
3. **Agente QA Explorador**: Monitora o 'Ready for Test', realiza o mapeamento dinâmico do DOM (HTML real), gera scripts Cypress em tempo real, executa os testes e anexa evidências visuais (.png) diretamente no Jira.

## 🛠️ Stack Técnica
- **Cérebro Local**: Ollama (`qwen2.5-coder:7b` / `llama3.3`)
- **Orquestração**: Python 3.13 (Agentes Independentes)
- **Gestão de Fluxo**: Jira Software API (Cloud/On-premise)
- **Automação E2E**: Cypress.io (Headless Mode)
- **Interface**: HTML5 / Tailwind CSS (Dark Mode Optimized)

## 🚀 Diferenciais do Projeto
* **Privacidade Total**: Todo o processamento de código e lógica de negócio ocorre localmente, sem envio de dados para APIs de terceiros.
* **Mapeamento Dinâmico**: O QA não "chuta" seletores; ele lê o código fonte real antes de criar a automação, eliminando falsos negativos.
* **Auto-Healing**: Se o DEV altera um ID, o QA identifica a mudança no próximo ciclo e atualiza o teste automaticamente.
